# Student Record Management System

## Overview

The Student Record Management System is a Python-based application used to manage student information efficiently. It provides basic CRUD operations and stores student records using CSV and JSON files.

## Features

- Add new student records
- View all student records
- Search for a student
- Update student information
- Delete student records
- Store data in CSV format
- Store data in JSON format
- Exception handling for invalid input
- Functions for modular and reusable code
- Simple menu-driven interface

## Technologies Used

- Python
- CSV
- JSON
- Exception Handling
- Functions
- File Handling

## CRUD Operations

### Create
Adds a new student record to the system.

### Read
Displays existing student records and allows students to be searched.

### Update
Modifies existing student information.

### Delete
Removes a student record from the system.

## Student Details

Each record contains:

- Student ID
- Name
- Department
- Year
- Email
- Marks

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code or another Python IDE.
4. Run the following command:

```bash
python student_management.py
```

5. Follow the menu displayed in the terminal.
